Getting Started

Install Moonwell, create a map from the template, and run it in Warcraft III.

On this page

Prerequisites Installation Create and run

Prerequisites

  • .NET 10 SDK
  • Warcraft III: Reforged 3.0.1
  • common.j and Blizzard.j in Documents\Warcraft III\JassHelper

Installation

Install the project template and the Moonwell command-line tool.

dotnet new install Moonwell.Templates
dotnet tool install --global Moonwell.Cli

Create and run

Create a project named MyMap, open its directory, and launch the map.

dotnet new moonwell -n MyMap
cd MyMap
moonwell run
